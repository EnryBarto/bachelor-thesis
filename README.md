# Progettazione e sviluppo di un Event Display 3D interattivo basato su OpenGL per il rivelatore SND@LHC

Sorgenti LaTeX e risorse della tesi sperimentale incentrata sulla progettazione e sullo sviluppo di un'applicazione di Computer Graphics 3D (OpenGL/C++) per la visualizzazione interattiva degli eventi del rivelatore SND@LHC al CERN.

Il progetto software descritto in questo documento è disponibile nel repository dedicato: [EnryBarto/sndsw/3dEventDisplay](https://github.com/EnryBarto/sndsw/tree/3dEventDisplay)

Tesi per il Corso di Laurea in Ingegneria e Scienze Informatiche presso l'Alma Mater Studiorum - Università di Bologna.

* **Candidato:** Enrico Bartocetti
* **Relatrice:** Prof.ssa Damiana Lazzaro
* **Correlatori:** Prof. Luigi Guiducci, Dott.ssa Giulia Paggi
